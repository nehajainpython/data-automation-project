This project automates data cleaning and feature engineering using Python and Pandas. The dataset was processed by removing duplicate records, generating email addresses automatically from names, formatting website URLs, and classifying records as Domestic or Foreign based on location. The final cleaned dataset was exported into CSV and Excel formats for easy analysis and reporting.

Features
Load and process CSV data
Remove duplicate records
Generate emails automatically
Standardize website URLs
Create classification columns using conditional logic
Export final cleaned data to CSV and Excel
Tools Used
Python
Pandas
OpenPyXL
